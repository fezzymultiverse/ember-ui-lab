# Ember V1.9.56 UI notes

The live Thinking card now keeps a fixed-height rotating status header. The spinner remains first, the header expands into a grey dotted activity timeline, and the detail icons distinguish web/page work, YouTube/downloads, Documents/files, Knowledge Graph work, image analysis, and API/provider calls. The animated ellipsis has a fixed-width slot so it cannot push the status text up, down, or sideways.

The composer plus button now removes the extra left inset and aligns with the chat content edge on narrow Android screens. Its existing menu, chips, keyboard handling and recording behavior are unchanged.
