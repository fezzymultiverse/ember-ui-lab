# Provider icon sources

The Groq, Mistral, Gemini, Cohere, Anthropic, OpenRouter and Stability AI SVG marks are bundled from `@lobehub/icons-static-svg` 1.101.0. That package is MIT-licensed; its upstream repository and npm package are:

- https://github.com/lobehub/lobe-icons
- https://www.npmjs.com/package/@lobehub/icons-static-svg

The Puter mark was bundled from the Dashboard Icons result for Puter:

- https://dashboardicons.com/icons/puter

The marks are used only to identify the corresponding providers. Brand assets remain the property of their respective owners. Providers without a sourced mark use a short monogram.
